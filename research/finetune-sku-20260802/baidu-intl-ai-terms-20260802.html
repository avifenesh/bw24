3B. CloudFlow Service

3B.1 Definitions

The CloudFlow service, built upon Baidu AI Cloud, provides data migration services to Baidu AI Cloud Object Storage (BOS).

3B.2 CloudFlow Special Service Terms

3B.2.1 To ensure secure data access, you shall create compliant source and destination access keys before using the CloudFlow service. These keys shall only be used for data transmission. After migration completion, you must promptly delete or revoke the key, or ensure source files remain readable by CloudFlow:

3B.2.1.1 You shall create a new read-only permission access key (AK/SK) for the source site data. During data migration, Baidu AI Cloud will use this key to retrieve source site data and upload it to the target bucket.

3B.2.1.2 You shall create a new access key (AK/SK) with read and write permissions for the target bucket. During data migration, Baidu AI Cloud will use this key to upload and verify the migrated data, which will then be stored in your target bucket. If you fail to create a new key as required or do not promptly delete or revoke the key, all resulting consequences and liabilities shall be borne solely by you.

3B.2.2 When using CloudFlow Services, you shall ensure continuous compliance with all personal data and privacy-related laws and regulations, including but not limited to obtaining consent from end users and/or data subjects, as well as rules concerning cross-border transfers of personal data that may apply to your use of CloudFlow services. If you violate applicable laws or regulations, Baidu AI Cloud reserves the right to suspend or terminate the data sync service provided to you, and you shall bear all resulting consequences and liabilities.

3B.2.3 When using the CloudFlow functionality for data migration, you shall independently verify the consistency between the migrated data and the source data. Please note that verifying the consistency between migrated data and source data is your sole responsibility. Baidu AI Cloud assumes no liability for any data inconsistencies discovered after migration completion.

3B.2.4 You understand and acknowledge that inconsistencies may exist between migrated data and source data. Therefore, Baidu AI Cloud specifically reminds you that performing a local backup is necessary and is also an effective way to ensure the security and integrity of your data. You should modify or delete source data only after completing the data migration and confirming its consistency with your original data.

3B.2.5 You understand and acknowledge that the migration speed is affected by factors such as the transmission efficiency of the source end, the size of the files being transferred, and the number of files being transferred, and that slow migration speeds may occur. Baidu AI Cloud shall not be liable for any slow data transmission.

3B.3.2.4 Before using the hard disk delivery service, you need to submit a requirements list, including but not limited to the number of hard disks and data cables to be migrated, the amount of data, the average size of data files, and the expected migration time. You must also designate the target region for data migration in advance and plan the data structure accordingly. After completing the above preparations, you should mail the hard disks, data cables, and any other required equipment. If the migration fails or errors occur due to incorrect information you provided, you shall bear sole responsibility.

3B.3.2.5 You shall create an access key (AK/SK) with read and write permissions for the target storage bucket. During data migration, Baidu AI Cloud will use this key to upload and verify the migrated data and store it in your target storage bucket. If you fail to create a new key as required or do not promptly delete or revoke the key, all resulting consequences and liabilities shall be borne solely by you.

3B.3.2.6 When using CloudFlow hard disk migration service, you shall ensure continuous compliance with all personal data and privacy-related laws and regulations, including but not limited to obtaining consent from end users and/or data subjects, as well as rules concerning cross-border transfers of personal data that may apply to your use of CloudFlow hard disk migration service.
