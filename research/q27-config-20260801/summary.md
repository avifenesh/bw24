# q27 shipping config — mirror-budget matrix on the board shape (2026-08-01)

Micro-sprint decision run: pick the SHIPPING config for the q27 board row from the
round-49 mirror-budget matrix. Box: darklanes-bench H100 (18.117.231.105), GPU 3
dedicated, tree = ~/arc4 (q4k-f16-mirrors lane binary, 49b: Q4_K+Q5_K f16 mirrors +
KQRP). Model: Qwen3.6-27B-Q4_K_M.gguf (NVMe, page-cached — 17s wall per full run).

## Method

Board shape exactly: `MEMRA_PROMPT_FILE=research/e2e/prompts/board-2048.txt` (2048
tokens), `MEMRA_NGEN=512`, `MEMRA_SPEC_K=3 MEMRA_SPEC_HPOST=1 MEMRA_SPEC_PMIN=0.3`.
One run-spec invocation per data point gives the real (prefill prime, plain decode,
spec decode) triple. Fresh process per run; nvidia-smi VRAM guard between configs
(vram-guard.log: 0 MiB before/after every run — clean teardown, no residue).
Phase 1 = one run per config; runs proved cheap (~17s), so N=3 was completed on ALL
three configs (interleaved A,B,C x3, same-session, ~08:57-09:03Z — covers both
plain- and spec-axis top-2 readings). All 9 runs: SELF-CONSISTENCY PASS.

Configs:
- **A** default: budget 32768 MB + KQRP on — 183 f16 mirrors (22.4GB), 449 KQRP tensors
- **B** raised: `MEMRA_PP_F16_BUDGET_MB=43008` + KQRP on — 265 mirrors (32.7GB), 449 KQRP
- **C** full-f16: `MEMRA_KQRP=0 MEMRA_PP_F16_BUDGET_MB=50688` — 288 mirrors (35.6GB), 96 q8rp

e2e = 512/(512/decode + 2048/prefill); the prefill term is that run's measured prime
seconds. Table generated by parse_matrix.py (per-run JSON rows + medians = verdict.txt).
